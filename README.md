# 视频总结助手 · YouTube & B站 AI Summary

一个 Chrome 侧边栏插件：在 YouTube / B站 视频页一键提取字幕，接入 OpenAI 兼容接口或本机 Antigravity 订阅，生成中文分层总结；支持追问对话、字幕点击跳转、结构化思维导图。所有时间戳（总结要点、章节、AI 回答、导图节点）都可以**点击直接跳转**到视频对应位置。

## 功能

| 页面 | 说明 |
|------|------|
| 总结 | 一句话 TL;DR + 关键要点（带时间戳）+ 章节摘要，流式生成；自动参考视频描述里的章节表与专有名词，生成后校验时间戳（越界的移除、轻微偏差吸附到真实字幕时刻，保证点击跳转准确），并自动质检（要点证据覆盖、时间线分布、内容重复），不达标会在顶部提示并可一键重试 |
| 对话 | 基于视频字幕的追问，自动附带当前播放位置上下文，多轮对话 |
| 字幕 | 带时间戳的字幕列表，点击跳转、自动跟随播放高亮、搜索、多轨道切换 |
| 导图 | AI 生成的结构化思维导图，可折叠/缩放/平移，节点点击跳转 |
| 历史 | 浏览总结过的所有视频记录（标题/平台/时间/内容类型），支持搜索；点击打开原视频并自动恢复当时的总结、对话与导图，可单条删除 |
| 设置 | 管理多套模型配置（新增/编辑/删除），一键测试连接，保存到本地；外观支持跟随系统 / 亮色 / 暗色，顶栏太阳/月亮按钮随时切换 |

## 安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本项目文件夹
4. （建议）在扩展管理页把本插件「固定」到工具栏

> 需要 Chrome 116+。点击工具栏图标即可打开侧边栏。

### Safari（macOS 26+ 本机试用）

Safari 没有 Chrome 的原生扩展侧边栏接口，因此 Safari 版点击工具栏图标后会打开一个独立小窗口，并绑定到当时的视频页签。功能与 Chrome 版共用同一份代码，Chrome 的安装方式不受影响。

1. 运行 `node tools/build-safari.mjs`
2. Safari → 设置 → 高级，打开「显示网页开发者功能」
3. Safari → 设置 → 开发者，打开「允许未签名扩展」，点「添加临时扩展」
4. 选择 `build/safari-extension`
5. 在扩展设置里启用插件，并允许访问 YouTube / B站及所配置的 AI 接口

临时扩展会在退出 Safari 或 24 小时后被移除。长期安装和分发需要用 Xcode / App Store Connect 将同一构建目录封装为 Safari Web Extension。

## 配置 AI

进入插件「设置」页，可以保存**多套模型配置**（配置名称 + API 地址 + Key + 模型）：点 **＋ 新增** 填写后 **测试连接**、**保存**；列表里点击任意一套即可切换为当前使用，也可以随时编辑/删除。侧边栏**顶部的下拉框**可以在任何页面一键切换当前模型，不用再进设置页改配置。新增的配置保存后会自动启用。

| 服务商 | API 地址 | 模型示例 |
|--------|----------|----------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 阿里通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Ollama 本地 | `http://localhost:11434/v1` | `qwen2.5`（Key 可留空） |
| 中转站 | 按服务商说明填写 | 按说明填写 |
| Antigravity 本机订阅 | 无需填写 API 地址或 Key | 登录后从 Gemini 模型列表选择 |

- 地址只需填到 `/v1`，插件会自动补全 `/chat/completions`；填完整路径也可以
- API Key **只保存在本地浏览器**（chrome.storage.local），不会发送到除你填写的 API 地址之外的任何地方
- 总结、对话、导图默认输出中文
- 生成过程中切换模型：进行中的请求继续用原模型跑完，完成后新操作才用新模型

### 使用 Antigravity 本机订阅（macOS）

1. 确保官方 Antigravity CLI 已安装并登录（终端执行 `agy models` 能看到模型）。
2. 首次使用双击 `connector/install.command`，连接器会随登录自动启动；只想临时运行可双击 `connector/start.command`。
3. 在插件设置中新增配置，模型来源选择 **Antigravity（本机订阅）**。
4. 点击 **连接并读取模型**，选择 Gemini 模型并保存。

连接器只监听 `127.0.0.1`，只调用官方 `agy`，登录令牌仍由系统钥匙串管理，不会保存到插件中。

## 使用

### YouTube

1. 打开任意一个 YouTube 视频页（有字幕的视频，含自动生成字幕）
2. 点击工具栏图标打开侧边栏
3. 「总结」页点 **总结本视频**，流式生成；没懂的地方切到「对话」直接问
4. 「字幕」页点击任意一句跳转；「导图」页一键生成结构化思维导图
5. 结果按视频缓存在本地，重开同一视频不重复扣费；需要更新点 **重新生成**

### B站

1. 同样打开视频页即可，操作与 YouTube 完全一致（支持多分P，按 P 缓存）
2. **重要**：B站的字幕列表（含 AI 字幕）只对登录用户开放，请先确保浏览器里已登录 B站账号
3. 字幕轨道可在「字幕」页切换（如「中文（自动）」等 AI 字幕 / 上传者的 CC 字幕；有 AI 字幕的视频还能选 AI 翻译出的英/日/西等多语言轨道）

## 常见问题

- **B站提示没有字幕**：先确认浏览器已登录 B站；AI 字幕部分视频还需要大会员。确实没有 CC 字幕的视频暂不支持（后续版本考虑接入转写）。
- **B站切视频/切分P 侧边栏没反应**：刷新一次视频页签（插件更新后旧页签可能还跑着旧脚本）。

- **提示"该视频没有可用字幕"**：视频连自动字幕都没有，第一版暂不支持（后续版本考虑接入转写）。
- **测试连接失败 401**：Key 不对或未授权；**404**：API 地址不对；**无法连接**：地址不可达，本地服务记得用 `http://` 开头。
- **字幕加载失败**：刷新 YouTube 页签（插件刚安装时，已打开的旧页签不会注入脚本）。
- **总结很慢/很长**：长视频会自动分段总结再汇总，属正常流程，阶段条会显示进度。
- **思维导图生成失败**：小模型可能输出不合规 JSON，重新生成或换更强的模型。

## 权限说明

- `sidePanel`：侧边栏 UI
- `storage` / `unlimitedStorage`：保存设置与按视频的总结缓存
- `scripting`：页面消息不通时自动补注入内容脚本
- `https://www.youtube.com/*`：读取视频信息与字幕、控制播放位置
- `https://www.bilibili.com/*`、`api.bilibili.com`、`*.hdslb.com`：B站视频信息与字幕获取（后台代理域名白名单，字幕列表依赖你浏览器里的登录 Cookie，插件不收集任何账号数据）
- `https://*/*`、`http://*/*`：允许访问你配置的任意 AI 接口地址（含本地 Ollama）

## 目录结构

```
manifest.json            # MV3 配置（YouTube + B站 双平台）
background/              # 后台：图标点击打开侧边栏 + B站 API 白名单代理
content/
  page-bridge.js         # YouTube 页面世界：播放器数据 / 签名字幕地址刷新
  bili-bridge.js         # B站页面世界：SPA 路由变化感知
  content.js             # 隔离世界（双平台）：字幕拉取 / 视频跳转 / 消息中转
sidepanel/               # 侧边栏 UI（原生 ES Modules，无构建）
  sidepanel.js           # 主编排：五个页面
  styles.css             # 深色设计系统
  modules/               # api / prompts / summarize / mindmap / markdown / store / subtitles
tools/                   # 图标生成、mock API
connector/               # Antigravity 本机连接器与一键安装脚本
```
